# @commonworks/dsh-circuit 0.1.3

面向初中/高中的电路模拟器 DSH 插件。这一版是**按真实浏览器逐条复现、再逐条修**的，
每条缺陷都变成了可复跑的自动化断言。

## 安装包

| 项 | 值 |
| --- | --- |
| 文件 | `commonworks-dsh-circuit-0.1.3.tgz` |
| 大小 | 561,970 字节 |
| SHA-256 | `e08245992e0c65e7c5596d1fee26a70159b8de59c93c2eaf02ca4e10b10fdc0e` |
| 文件数 | 357 |

校验：

```powershell
certutil -hashfile commonworks-dsh-circuit-0.1.3.tgz SHA256
```

> 校验和记在这里、不记在 `INSTALL.md` 里，是因为 `INSTALL.md` **本身在发布包内**——
> 把包的哈希写进包内文件会让哈希永远对不上（实测：改一行注释，哈希由
> `fa2723e5…` 变成 `b125a3b0…`，即形成"文档里的校验和永远校验不了自己"的死循环）。
> 打包是幂等的：同一个工作区连续打两次，哈希完全相同，校验和因此可信。

## 一行安装

```powershell
dsh plugin --profile web add @commonworks/dsh-circuit
```

或从本 Release 的 tgz 装：

```powershell
dsh plugin --profile web add https://github.com/sdaniasdsd/dsh-teaelc/releases/download/v0.1.3/commonworks-dsh-circuit-0.1.3.tgz
```

装完重启 `dsh web` 并刷新浏览器，打开 `http://127.0.0.1:<端口>/dsh-circuit/`。
自检：`/dsh-circuit/api/health` 返回 `{"ok":true,"engine":"circuitjs1",...}`。

## 修了什么

### P0 直接挡住客户使用

- **浮窗关掉后再无入口**：误点标题栏 ×，整个插件变砖，刷新也无法恢复（刷新会从
  本地记忆恢复成关闭态）。现加常驻「面板 ▾」菜单，可重开任意窗口，并可一键
  「恢复默认布局」。
- **窗口坐标跨分辨率不设限**：在 1920 显示器上摆好，换 1366 笔记本后窗口跑到视口外
  且拖不回来。现几何一律夹进当前视口（先挪、挪不动再缩），拖动过程即时夹取，
  视口变化时重新夹取。
- **示波器画布高度写死 200px**：拉大窗口，波形仍是窄带。现由 flex 撑满并用
  ResizeObserver 跟随，缩放时按帧节流重设位图。
- **第一次打开没有任何说明**：菜单栏被 CSS 移出可视区、元件名是英文。现首次自动
  展开「怎么用」，写清 放元件→连线→接地→看读数→看波形 五步。

### P1 功能/数据是错的

- **通道跨电路串号**：换一份电路后，旧通道按「第几个元件」去新电路里重新绑定，
  显示的是**另一个元件的数值**——数字正常但是错的，比报错更危险。现按电路代次
  作废，明确标「已断开 · 换过电路」，重新选择测点即恢复。
- **单次触发从不冻结**：触发电平变量从未赋值（判断条件恒假）；且单调信号
  （RC 充电）物理上没有第二个边沿。现支持边沿触发 + 按采样点数兜底，并两个
  运行按钮状态同步。
- **示波器面板加的通道没有名字、测量台不高亮**：现统一命名（带元件序号与参数，
  如 `电阻#0 100 Ω 电流`）并正确高亮。
- **电流通道默认接错元件**：默认绑到电位器滑杆或导线。现按教学意义排序。
- 另修：两个运行按钮状态不同步、AC 耦合切一下就清空样本、电压/格 去量电流、
  改元件值后通道名不刷新。

### P2 控制台噪声与死代码

- 上游缺失的 `images/hborder.png`、`service-worker.js` 由 Host 侧给合法空响应；
  shell 内联 favicon；`is-embed` 补上真正的 CSS；删掉只写不读的 state 字段。

## 验证

```powershell
cd dsh-circuit
npm test               # 21 条：路由 / 清单契约 / Host 栅栏
npm run test:browser   # 60 条：真 Chrome 跑真页面，五个套件
```

`test:browser` 需要本机有 Chrome。其中「客户端半边」套件按 `app.asar` 里的真实装载
协议与 slots 契约复刻宿主，**真正执行 `client/client.js`** —— 0.1.0 的「装完看不见」
事故就死在这一半，而当时 Host 路由测试是全绿的。
