# dsh-circuit 可用性修复清单（依据真浏览器实测）

测试环境：puppeteer-core 25.14 + 本机 Chrome，经 dev-tools/browser/serve.mjs 挂载真实路由，
1400×900 与 1366×768 两种视口。以下每条都是**实测复现**，不是推测。

## P0 — 会直接挡住客户使用

1. **关掉任一浮窗就再也打不开（无恢复入口）**
   实测：点全部 4 个窗口的 × 后 `visibleWins=0`，页面上没有任何"恢复/重置布局"按钮，
   唯一文字是 toast。客户误点一次 ×，整个插件就废了，必须刷新页面。
   修：加"面板"菜单（标题栏左侧固定小按钮）+ localStorage 记忆 + 一键恢复默认布局。

2. **窗口位置/尺寸跨屏幕不设限 → 客户换分辨率后窗口跑到屏幕外**
   实测 1366×768 下默认布局刚好贴边（presets 右边界 1262 / 下边界 574）。
   但窗口被存到 localStorage 后换小屏，坐标原样恢复 → 窗口在可视区外，且同样没有恢复入口。
   修：`loadGeom` 时做视口夹取（夹进可视区、至少留 40px 标题栏可见）。

3. **窗口可以拖出屏幕左/上边界后无法再拖回来**
   实测 `startMoveWin` 只做 `Math.max(0, ...)`，右/下方向完全不限制。
   修：拖动中与拖动结束都做视口夹取。

4. **示波器画布高度固定 200px，窗口拉高后波形不跟着变**
   实测：窗口 422→550 高，canvas 200→200（只宽度跟着变）。客户拉大示波器窗口看到的仍是一条窄带。
   修：canvas 高度跟随容器（flex + ResizeObserver）。实测还发现**拖动缩放时没有重设 bitmap**。

5. **没有任何"帮助/说明"，客户不知道下一步做什么**
   元件快选里没有菜单、菜单栏被 CSS 移出屏幕，客户第一次打开只看到一堆框。
   修：加"帮助"浮窗（默认打开一次，可关闭，可再从面板菜单打开），写清 4 步操作。

## P1 — 功能错误（数据/交互是错的）

6. **`addProbeChannel` 加的通道，测量台对应行不高亮、通道名是空字符串**
   实测：用示波器"+ 电流通道"后 `channels=[{key:"I-1794301655507",label:""}]`，表格 `litRows=0`。
   根因：该函数 push 的通道 `label:''` 且没有调用 `updateChannelLabel`，`renderTable` 的高亮
   判定用的是旧式 `c.type===e.type && c.index===e.index`，对 `measure:'current'` 型永远不成立。
   修：加通道后统一走 `updateChannelLabel`，并让高亮判定认新式通道。

7. **同一通道名重复/单位错乱**：通道名形如"电阻 电压"，同类型元件（一电路里 3 个电阻）
   完全无法区分。实测 LRC 电路里 7 个元件里 3 个"电阻"。客户选通道时无法分辨。
   修：用内核 `getInfo()` 的真实参数（如 `R = 1 kΩ`）拼通道名，并加序号。

8. **单次触发（Single）不冻结，测不到**
   实测：切到"单次触发"后 `sampleCount` 继续涨到 189，`runBtn` 仍是"运行"，
   说明触发条件从未成立（`triggerRef` 永远是 null → `meanish = v0` → `v0 > meanish` 恒 false）。
   修：用窗口内采样均值/峰峰中值作为参考电平，边沿检测按参考电平判定。

9. **示波器窗口"运行/已暂停"按钮与测量台按钮状态不同步**
   实测：点测量台"暂停仿真"后，示波器按钮仍显示"运行"。
   修：`renderSimState` 里同时更新 `ui.scopeRunBtn`。

10. **AC 耦合会清空全部采样，导致切换瞬间波形空白且读数消失**
    修：切换耦合不清空样本（耦合只在绘制时减均值，样本无需重建）。

11. **`renderTable` 结构签名不含"元件参数"，改元件值后表格不自刷**
    实测：把电阻从 1k 改成 2k，表格数值靠 500ms 轮询更新（能刷），但通道名/下拉选项里的
    参数值不会更新。修：签名里带上 info 摘要。

12. **电流通道默认选中第一个"可测电流"元件，实测是 VarRailElm/导线而不是电阻**
    实测：`+ 电流通道` 默认绑 `VarRailElm`。对初中教学这几乎总是错的。
    修：优先选有测量意义的元件（电阻/LED/灯泡/电容/电感/电流表），导线与电源排在后面。

## P2 — 稳健性 / 体验

13. **`/dsh-circuit/app/images/hborder.png` 404**（上游 CSS 引用）→ 控制台报错，客户会以为坏了。
    修：补一个 1×1 透明 PNG（上游 menu bar 已移出屏幕，视觉无影响）。
14. **`service-worker.js` 404** → 上游自动注册 SW 失败，控制台报错。
    修：宿主侧对该路径返回空 200（或提供一个空 SW 并 unregister）。选：提供一个"立即注销自身"的 SW。
15. **favicon.ico 404** → 补 favicon（在 shell 里内联 data URI 即可）。
16. **`is-embed` class 声明了但 CSS 里根本没有对应规则**（死代码）。
17. **`AMPS_PER_DIV`、`probeChip` 探针 SVG、`probeIconSvg` 部分未被使用 / 电流档位下拉只列电压档**：
    实测"电压/格"下拉只有 V 单位档位，但通道可能是电流 → 选 1 V/格 去量 50mA。
    修：档位下拉按当前启用通道的单位切换（V/格 或 A/格）。
18. **`state.elementAt` 只写不读**（死字段）。
19. **失败提示不可见**：toast 定位 `bottom:40px` 居中被示波器窗口盖住。实测截图里 toast 在底部中央，
    被画布挡住一半。修：toast 提到顶部居中 + z-index。
