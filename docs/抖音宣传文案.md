# 抖音宣传文案草稿 · 电路小实验

> 用法：每条都是独立成片的口播稿。带【画面】的是拍摄提示，不是要念的内容。
> 所有功能点都对应实际已实现的功能，可直接演示；文末「不要说的」列了尚未完成的部分。

## 版本一：作品自述（推荐首发）

**时长**：50 秒左右

【画面】DeepSeek Harness 界面，光标停在聊天框

**口播**
「我给 DeepSeek Harness 写了一个插件。
不是那种聊天增强、也不是什么效率工具——
**是一个电路模拟器。**」

【画面】左侧边栏出现电路图标，点开，中间主区展开一整块画布

**口播**
「装上之后，它就在 DSH 左边多出来一个位置。
点开，**一整块电路画布**铺在中间，右边是我的中文控制面板。」

【画面】拖放电阻、电源、导线，回路闭合，电流开始流动

**口播**
「元件直接拖上去：电阻、电容、电感、二极管、LED、电流表、示波器探头，一共 18 种。
回路一闭合，**电流立刻开始跑**——不是动画，是真的在解电路方程。」

【画面】右侧测量台读数跳动，特写

**口播**
「右边这张表，每个元件的电压、电流是**实时仿真读数**。
单位还自动切：毫安、微安、纳安。」

【画面】点电压通道，波形出现；拖动滑块，波形幅度变化

**口播**
「最关键的是示波器。
电压表只告诉你"现在多少伏"，示波器告诉你"**它是怎么变的**"。
电容充电那条曲线、交流电那个正弦波，全都看得见。」

【画面】点"电压通道"和"电流通道"，两个通道并排

**口播**
「而且电压和电流是**分开的两个通道**：
电压走探头，两个探头相减就是电位差，跟真示波器接线一样；
电流直接选一个元件读。单位也分开显示，不会混淆。」

【画面】点"经典电路"，依次加载欧姆定律、LRC 谐振

**口播**
「还塞进去 23 个经典电路：初中的欧姆定律、串并联，高中的 LRC 谐振、戴维南定理，大学的运放、全波整流。
点一下加载，学生可以在这个电路上随便拆、随便改。」

【画面】框选放大波形细节

**口播**
「滚轮缩放、框选放大——想看哪段波形，拉个框就放大到那里。」

【画面】回到 DSH 聊天界面

**口播**
「这就是我做的 DSH 插件。
它不是聊天工具，是**一个能让学生亲手拆电路的地方**。
电学，终于能看见了。」

## 版本二：功能速览（信息密度型）

**时长**：35 秒

【画面】快速剪辑，每句话配一个操作

**口播**
「我给 DeepSeek Harness 做了个电路模拟器插件，半分钟给你看全。」

「**一：18 种元件随便拖**——电阻、电容、电感、二极管、LED、电流表、示波器探头。」

「**二：逐元件实时读数**——电压、电流，单位自动 mA、μA 切换。」

「**三：真·示波器**——10 格网格、时基 10 微秒到 3 秒、AC/DC 耦合、单次触发。」

「**四：电压电流分开测**——电压走双探头测电位差，电流选元件直接读，单位不混。」

「**五：滚轮缩放、框选放大**——想看细节，拉个框就放大。」

「**六：23 个经典电路**——初中到大学，点一下加载。」

【画面】左侧边栏图标特写

**口播**
「它就挂在 DSH 左边栏里，点开即用。」

「电学，终于能'看见'了。」

**口播**
「把电阻拖大一点，电流立刻变小——**欧姆定律是自己浮出来的**，不是背下来的。」

【画面】打开经典电路库

## 不要说的（尚未完成 / 需要诚实）

以下几项**当前状态不支持或未验证**，文案里不要说：

1. **「左侧边栏一键打开」** —— 侧栏图标代码已写，但客户端 bundle 目前没被宿主加载（`/plugins/dsh-circuit/client.js` 返回 404），需要重启 DSH 后确认。**没确认前，"挂在左边栏"这句只能拍"代码写好了"，不能说"装好就能用"。**
2. **「频谱分析 / FFT」** —— 内核有 FFT 能力，但没接出来。现在只有峰峰值、RMS、频率三个读数。
3. **「自动判题 / 挑战任务」** —— 挑战功能已删除，现在没有自动评分。
4. **「多通道双纵轴」** —— 电压和电流通道目前共用同一纵轴量程，同时开两条不同单位的通道时，纵轴标注只按单一单位显示。
