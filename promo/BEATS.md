## 音频合成链

1. `audio.py` → `music.wav`（纯 numpy 原创配乐，读 CUTS + CLICKS + 音效点）
2. `voice.py`（SAPI）→ 12 段 `voice/NN.wav`，按上表时间轴错位贴到 65s 长轨 → `voice_track.wav`
3. ffmpeg `sidechaincompress`：旁白压配乐（ducking，ratio 3:1，release 300ms）
4. 成片 `loudnorm I=-17:TP=-1.5`

## 渲染管线

```bash
NODE_PATH="D:/Apps/eac-design-world/node_modules" node render.js --film film.html   # 1950 帧
python audio.py      # music.wav
python make_voice.py # voice_track.wav
ffmpeg -y -framerate 30 -f image2 -c:v mjpeg -i out/f_%05d.jpg \
  -i music.wav -i voice_track.wav \
  -filter_complex "[1:a][2:a]sidechaincompress=...[mus];[mus][2:a]amix..." \
  -c:v libx264 -crf 17 -preset medium -pix_fmt yuv420p -movflags +faststart \
  "电路小实验 DSH 插件 65s.mp4"
```
